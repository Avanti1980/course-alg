量水问题 一般化

两个无刻度水桶，总容量分别为$a$升和$b$升

  1. 是否可以量出$t$升的水？
  2. 如果可以，请给出具体方案，其中$a$、$b$、$t$都是正整数

思路：装满对应$+a$或$+b$，倒掉对应$-a$或$-b$

能否通过若干次$\pm a$、$\pm b$得到$t$？即存在整数$x$、$y$使得$ax + by = t$？

前面的例子：$5 \cdot 3 - 7 \cdot 2 = 1$

由裴蜀定理，$t$必须是$a$、$b$最大公约数的倍数，若$t=1$，则$a$、$b$互素

量水问题 一般化

原问题：是否存在整数$x$、$y$使得$ax + by = t$？

问题 1：求最大公约数 (greatest common divisor)

输入正整数$a$、$b$，输出$d = \gcd(a,b)$

令$a \gets a / d$、$b \gets b/ d$、$t \gets t / d$，此时问题不变但$\gcd(a,b) = 1$

问题 2：求整数$x$、$y$

输入互素的正整数$a$、$b$，输出整数$x$、$y$使得$ax+by=1$

$x \cdot t$、$y \cdot t$就是原问题的解

暴力穷举

问题 1：输入正整数$a$、$b$，输出$d = \gcd(a,b)$

$1$必然是公约数

从$2$遍历到$\min(a,b)$，最大能同时整除$a$、$b$的数就是最大公约数

def gcd(a: int, b: int) -> int:
    d = 1
    for i in range(2, min(a, b) + 1):  # 最大公约数不会大于两者中的较小者
        if a % i == 0 and b % i == 0:  # 同时整除即为公约数
            d = i
    return d
暴力穷举

问题 2：输入互素的正整数$a$、$b$，输出整数$x$、$y$使得$ax+by=1$

定理：$\{ 0, a, \ldots, (b-1) a \}$中的$b$个数除以$b$的余数恰为$0, 1, \ldots, b-1$

证明：设$i \ne j$且$ia \equiv ja \bmod b$，则$b \mid (i - j) a$，又$a$、$b$互素，故$b \mid (i - j)$，注意$i, j \in \{ 0, 1, \ldots, b-1 \}$，即$|i - j| < b$，只能是$i = j$，矛盾

若$ax+by=1$，则$ax \bmod b = 1$，恰为剩余系中除$0$外的某个数

def coef(a: int, b: int, t: int, d: int) -> tuple[int, int]:
    if t % d != 0:
        raise ValueError("t必须是最大公约数d的倍数")
    a, b, t = a // d, b // d, t // d  # 此时 a b 互素
    for x in range(b):         # 0 a 2a ... (b-1)a 构成一个模 b 的剩余系
        if (a * x) % b == 1:
            y = (1 - a * x) // b
            return t * x, t * y

用数论领域的术语，集合$\{ 0, a, \ldots, (b-1) a \}$构成模$b$的完全剩余系

辗转相除

欧几里得《几何原本》第七卷 约公元前 300 年

记$a = b \cdot q + r$且$r < b$，故$\gcd(a,b) \mid a - b \cdot q = r$

于是$\gcd(a,b) \mid \gcd(b,r)$，同理可证$\gcd(b,r) \mid \gcd(a,b)$，故两者相等

不断令$(a,b) \gets (b,r)$直到$b = 0$停止循环，此时$a$就是最大公约数

def Euclidean(a: int, b: int) -> int:  # 辗转相除
    while b:
        a, b = b, a % b
    return a
  • 暴力穷举循环轮数约为$\min(a, b)$，每轮做$2$次取模运算
  • 辗转相除循环轮数约为$\log(\max(a,b))$，每轮做$1$次取模运算

拉梅定理证明了辗转相除的最坏情况出现在$a$、$b$为相邻斐波那契数时

辗转相除

$a = b \cdot q + r$，不断令$(a,b) \gets (b,r)$，用递归替代循环可得到系数

  • 若$\class{blue}{d} = b \cdot \class{blue}{x} + r \cdot \class{blue}{y}$，则$\class{blue}{d} = b \cdot x + (a - b \cdot q) \cdot y = a \cdot \class{blue}{y} + b \cdot \class{blue}{(x - \lfloor a / b \rfloor \cdot y)}$
  • 当$b = 0$时，$a$就是最大公约数，此时$d = \class{blue}{a} = a \cdot \class{blue}{1} + b \cdot \class{blue}{0}$
def Euclidean_extended(a: int, b: int) -> tuple[int, int, int]:
    # 返回 (d, x, y) 使得 ax + by = d = gcd(a, b)
    if b == 0:
        return a, 1, 0
    else:
        d, x, y = Euclidean_extended(b, a % b)
        return d, y, x - (a // b) * y


def Euclidean_coef(a: int, b: int, t: int) -> tuple[int, int]:
    d, x, y = Euclidean_extended(a, b)
    if t % d != 0:
        raise ValueError("t必须是最大公约数d的倍数")
    t = t // d
    return t * x, t * y
  • 求系数：暴力穷举循环轮数为$b$，辗转相除循环轮数约为$\log(\max(a,b))$
更相减损

《九章算术》第一卷“方田”章的“约分术”，约公元前 100 年

原文：可半者半之，不可半者，副置分母、子之数，以少减多，更相减损，求其等也。以等数约之。

现代白话文：如果分子和分母都是偶数，就先同除以 2 (将它们减半)；如果不能同除以 2，就把分母和分子并列放置，用大数减去小数，反复减来减去，直到减得两数相等 (这个“等数”，即最大公约数)。最后用这个“等数”去约简 (除以) 分子和分母。

更相减损

$\gcd(a,b) = \gcd(a-b,b)$，不断令$(a,b) \gets (a-b,b)$直到$a=b$

def alternative_subtraction(a: int, b: int) -> int:  # 更相减损
    shift = 0  # 最大公约数的质因子分解中 2 的幂次
    while not (a & 1) and not (b & 1):  # a、b 均为偶 2是公因子
        a >>= 1  # a <- a / 2
        b >>= 1  # b <- b / 2
        shift += 1
    while True:
        if a > b:
            a = a - b
        elif a < b:
            b = b - a
        else:
            return b << shift
  • 避免了低效的取模运算，只做加减法和移位
  • 最坏情况下循环轮数为$\max(a, b)$，例如$\gcd(10000,1)$
改进的更相减损

更相减损没有将“可半者半之”应用到极致

def gcd_opt(a: int, b: int) -> int:  # 改进的更相减损
    shift = 0  # 最大公约数的质因子分解中 2 的幂次
    while not (a & 1) and not (b & 1):  # 均为偶 2是公因子
        a >>= 1  # a <- a / 2
        b >>= 1  # b <- b / 2
        shift += 1
    # 此时 2 已不再是公因子
    while not (a & 1):  # a 不断除以 2 变成奇数
        a >>= 1
    while b:
        while not (b & 1):  # b 不断除以 2 变成奇数
            b >>= 1
        if a < b:
            a, b = b, a  # 确保 a 大 b 小
        a -= b  # 更相减损 新的 a 必为偶
    return a << shift

循环轮数约为$\log(\max(a, b))$，同辗转相除，但避免了取模运算

如何证明算法中循环结构的正确性？

循环不变式 (loop-invariant)：一个关于循环状态的命题，满足：

  1. 初始：在初次进入循环前成立
  2. 保持：若每次进入循环前成立，则下次进入循环前还成立
  3. 终止：循环可以终止，此时循环不变式提供一个有用的性质
冒泡排序 正确性 
def bubble_sort(a: list[int]) -> None:
    n = len(a)
    for i in range(n-1):
        for j in range(n-1, i, -1):  # 从后往前遍历，将较小的元素像气泡一样浮到前面
            if a[j] < a[j-1]:
                a[j], a[j-1] = a[j-1], a[j]

内层：每次进入循环前，子数组$a[j, \ldots, n-1]$的第一个元素最小

  1. 初始：$j = n-1$，子数组$a[n-1]$只有一个元素，循环不变式显然成立
  2. 保持：若$a[j]$是$a[j, \ldots, n-1]$中最小的，循环中比较$a[j-1]$和$a[j]$并将小者置于前，则再次进入循环前$a[j-1, \ldots, n-1]$的第一个元素最小
  3. 终止：$j = i$，此时子数组$a[i, \ldots, n-1]$第一个元素最小

外层：每次进入循环前，子数组$a[0, \ldots, i-1]$有序排列着整个数组最小的$i$个元素

def bubble_sort(a: list[int]) -> None:
    n = len(a)
    for i in range(n-1):
        for j in range(n-1, i, -1):  # 从后往前遍历，将较小的元素像气泡一样浮到前面
            if a[j] < a[j-1]:
                a[j], a[j-1] = a[j-1], a[j]

内层：每次进入循环前，子数组$a[j, \ldots, n-1]$的第一个元素最小

外层：每次进入循环前，子数组$a[0, \ldots, i-1]$有序排列着整个数组最小的$i$个元素

  1. 初始：$i=0$，子数组$a[0, \ldots, -1]$为空，循环不变式显然成立
  2. 保持：若子数组$a[0, \ldots, i-1]$有序排列着整个数组最小的$i$个元素，又内层循环终止时$a[i, \ldots, n-1]$的第一个元素最小，因此子数组$a[0, \ldots, i]$亦有序排列着整个数组最小的$i+1$个元素
  3. 终止：$i = n-1$，此时子数组$a[0, \ldots, n-2]$有序排列着整个数组最小的$n-1$个元素，故剩余的$a[n-1]$是最大元素，从而整个数组已排好序

\begin{align} T = c_0 & + c'_0 + c_1 + c'_1 (n-1) + c''_1 n + c_2 (n-1) + c'_2 \frac{n^2-n}{2} \\ & + c''_2 \frac{n^2+n-2}{2} + c_3 \frac{n^2-n}{2} + c_4 \sum_{i=0}^{n-2} t_i = a n^2 + b n + c + c_4 \sum_{i=0}^{n-2} t_i \end{align}

冒泡排序 时间分析

\begin{align} T = a n^2 + b n + c + c_4 \sum_{i=0}^{n-2} t_i \end{align}

$t_i$是外层循环第$i$轮中内层循环$a[j]$和$a[j-1]$交换的次数

  • 最好情况下 (初始顺序) 发生$0$次
  • 最坏情况下 (初始逆序) 发生$n-1-i$次

\begin{align} a n^2 + b n + c & \le T \le a n^2 + b n + c + c_4 \sum_{i=0}^{n-2} (n-1-i) \end{align}

综上，冒泡排序的时间复杂度为$\Theta(n^2)$

  • 二次函数的系数$a$、$b$、$c$与具体执行算法的计算机有关，将其忽略
  • 我们仅关注问题规模达到一定程度时的时间复杂度，当$n$足够大时，二次函数中的一次项、常数项可以忽略

$\Theta$是渐近符号，暂且理解为“相当”，其严格定义我们将在第二讲“函数的增长”中学习

插入排序

类似打牌时摸牌理牌的过程，手上始终是理好序的牌，每摸一张新牌，将其插入适当的位置，保持牌序不被破坏

def insertion_sort(a: list[int]) -> None:
    n = len(a)
    for i in range(1, n):
        key = a[i]
        j = i - 1
        while j >= 0 and key < a[j]:
            a[j+1] = a[j]
            j -= 1
        a[j+1] = key

内层：每次进入循环前，$key \le a[j+1]$

  1. 初始：$key = a[i] = a[j+1]$
  2. 保持：内层循环的进入条件之一是$key < a[j]$，进入后$j$自减$1$变成$j'$，那么下次进入循环前显然有$key < a[j] = a[j'+1]$
  3. 终止：循环条件不被满足，要么$j=-1$即$key < a[0]$，要么$key > a[j]$

外层：每次进入循环前，子数组$a[0, \ldots, i-1]$已经排好序

归并排序

分治：将原问题分成若干同类型、规模更小的子问题递归求解

  • 分：将$a[low, \ldots, high]$分成$a[low, \ldots, mid]$、$a[mid+1, \ldots, high]$两部分，为使子问题规模相同，$mid$为$(low + high)/2$取整
  • 治：分别对$a[low, \ldots, mid]$和$a[mid+1, \ldots, high]$进行排序，递归实现
  • 合：将排好序的$a[low, \ldots, mid]$、$a[mid+1, \ldots, high]$合并成$a[low, \ldots, high]$
def merge_sort(a: list[int], low: int, high: int, temp: list[int]) -> None:
    if low < high:
        # 分：计算分解的中间点
        mid = (low + high) // 2
        # 治：递归调用
        merge_sort(a, low, mid, temp)
        merge_sort(a, mid+1, high, temp)
        # 合：合并已排好序的两个子数组
        merge(a, low, mid, high, temp)

def merge(a: list[int], low: int, mid: int, high: int, temp: list[int]) -> None:
    # a[low:mid+1]、a[mid+1:high+1]已排好序
    # 拷贝数据到临时数组
    temp[low:high+1] = a[low:high+1]

    # i = low -> mid
    # j = mid+1 -> high
    i, j, k = low, mid+1, low
    while i <= mid and j <= high:
        if temp[i] <= temp[j]:
            a[k] = temp[i]
            i += 1
        else:
            a[k] = temp[j]
            j += 1
        k += 1

    if i <= mid:  # 拷贝 left 的剩余元素
        a[k:high+1] = temp[i:mid+1]

归并排序 时间分析

设将两个长度为$n/2$的有序数组合并的时间为$f(n)$

  • 最好情况：其中一个的最大元素小于另一个的最小元素，$f(n) = n/2$
  • 最坏情况：一直要比到两个数组的最大元素，$f(n) = n-1$

设长度为$n$的数组的排序时间为$T(n)$，则有递推关系

\begin{align} T(n) = \begin{cases} 1, & n = 1 \\ 2 \cdot T (n/2) + f(n), & n > 1 \end{cases} \end{align}

为求$T(n)$，假设

  • $n = 2^t$，其中$t$为某个正整数，这样等号右边的$n/2$总是除得尽
  • $f(n) = c \cdot n$，其中$c$为某个正常数

\begin{align} T(2^t) = \begin{cases} 1, & t = 0 \\ 2 \cdot T (2^{t-1}) + c \cdot 2^t, & t > 0 \end{cases} \end{align}

归并排序 时间分析

\begin{align} \begin{array}{lrclcl} (\spadesuit) & T(2^t) & = & 2 \cdot T (2^{t-1}) & + & c \cdot 2^t \\ (\heartsuit) & T(2^{t-1}) & = & 2 \cdot T (2^{t-2}) & + & c \cdot 2^{(t-1)} \\ & & \vdots & \\ (\clubsuit) & T(2^1) & = & 2 \cdot T (2^0) & + & c \cdot 2^1 \end{array} \end{align}

令$(\spadesuit) + (\heartsuit) \cdot 2 + \cdots + (\clubsuit) \cdot 2^{t-1}$，代入$n = 2^t$、$t = \lg n$、$T(2^0) = 1$可得

\begin{align} T(n) = T(2^t) = 2^t \cdot T(2^0) + c \cdot t \cdot 2^t = n + c \cdot \lg n \cdot n = \Theta (n \lg n) \end{align}

快速排序

分治：将原问题分成若干同类型、规模更小的子问题递归求解

  • 分：将最后一个元素作为主元 (pivot)，确定其在排好序的数组中的正确位置$m$，将小于、大于主元的元素分别挪到主元的左边、右边
  • 治：分别对子数组$a[low, \ldots, m-1]$和$a[m+1, \ldots, high]$进行递归排序
  • 合：什么也不做
def quick_sort(a: list[int], low: int, high: int) -> None:
    if low < high:
        # 分：计算主元位置并将其它元素挪到主元左右
        m = partition(a, low, high)
        # 治：递归调用
        quick_sort(a, low, m-1)
        quick_sort(a, m+1, high)

快速排序由英国计算机学家 Tony Hoare (1980 年图灵奖得主) 于 1959 年提出，迄今依然是最流行的排序算法

快速排序 
def partition(a: list[int], low: int, high: int) -> int:
    pivot = a[high]  # 最右元素作为主元

    # i指向小于主元的元素的存放位置 初始为最左
    i = low

    # low -> high-1 遍历其它元素
    for j in range(low, high):
        if a[j] <= pivot:
            # 小于主元的元素放到主元左边
            a[i], a[j] = a[j], a[i]
            i += 1  # 存放位置右移一位

    # 所有小于主元的元素已位于主元左边
    # 当前的i就是主元应该放的位置
    # 当前的a[i]大于主元
    a[i], a[high] = a[high], a[i]

    return i

快速排序 时间分析

确定主元正确位置、移动其它元素到主元的左右所需时间为$\Theta(n)$

设长度为$n$的数组的排序时间为$T(n)$，则有递推关系

\begin{align} T(n) = \begin{cases} 1, & n = 1 \\ T(n) = T(k) + T(n-1-k) + c \cdot n, & n > 1 \end{cases} \end{align}

  • 最好情况：主元是中位数，产生两个规模为$n/2$的子问题，此时递推关系为$T(n) = 2 \cdot T (n/2) + c \cdot n$，同归并排序，$T(n) = \Theta(n \lg n)$
  • 最坏情况：主元是最大或最小元素，只产生一个规模为$n-1$的子问题，此时递推关系为$T(n) = T (n-1) + c \cdot n$，易知有$T(n) = \Theta(n^2)$

如何改进？

  • 随机选取主元：简单有效，大概率避免最坏情况
  • 三数取中法：随机取三个元素的中位数作为主元
  • 混合策略：子问题规模较小时切换为插入排序 (实际库函数的常用技巧)
归并排序 vs. 快速排序

归并排序在最坏情况下仍能保证$\Theta(n \lg n)$，理论上最优；快速排序在实际工程实践中更受青睐：

  • 归并排序在合并两个有序子数组时需存储等大的辅助数组，递归过程中频繁的内存申请与释放会带来显著的性能开销
  • 快速排序的期望时间复杂度也为$\Theta(n \lg n)$，即主元选取不当导致的时间复杂度退化是小概率事件；快速排序是原址排序 (in-place sort)，仅需对连续内存区间内的元素进行就地交换，在 CPU 缓存命中率和空间效率上更优

为什么研究算法

算法是计算技术的核心：它不仅决定程序快慢，更决定问题能否求解

  • 升级硬件可以提速，但提升往往有物理上限
  • 选择更优的算法，带来的提升可以是数量级的，甚至是决定性的

如果计算资源无限，还需要研究算法吗？

  • 硬件再快也终归有限；而大数据时代，问题规模的增长远超硬件进步
  • 好的算法让我们能解决更大、更难的问题
  • 算法素养是每位计算机研究者的核心能力
